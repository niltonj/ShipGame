# ShipGame

Jogo de nave com scrolling vertical desenvolvido em JavaScript.

## Como Jogar

1. Abra o arquivo `index.html` em um navegador web
2. Use as setas do teclado ou WASD para mover a nave
3. Pressione espaço para atirar (ou clique com o mouse)
4. Você também pode jogar usando apenas o mouse - mova o mouse para controlar a nave e clique para atirar

## Objetivos

- Destrua os inimigos para ganhar pontos
- Cada inimigo vale 10 pontos
- Ao atingir 500 pontos, um chefão aparecerá
- Derrote o chefão para vencer o jogo!
- Você tem 3 vidas - não deixe os inimigos ou seus tiros te atingirem

## Funcionalidades

- Scrolling vertical com fundo de estrelas
- Controle por teclado ou mouse
- Inimigos que atiram de volta
- Chefão com barra de vida que aparece aos 500 pontos
- Mensagem de vitória ao derrotar o chefão
